# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público. Repórtala en privado por cualquiera de estas vías:

- Correo: CORREO_DEL_PROYECTO
- GitHub: pestaña **Security** del repositorio → **Report a vulnerability** (reporte privado de vulnerabilidades).

Incluye una descripción, los pasos para reproducirla y el impacto que esperas. Respondemos lo antes posible y te avisamos cuando esté corregida.

## Alcance

La app, la web pública, las funciones de Supabase y este repositorio. Por diseño, el servidor no guarda datos personales; cualquier hallazgo que permita relacionar reportes, notificaciones o registros con una persona se considera grave.

## Incidentes

Si una vulnerabilidad compromete datos personales, seguimos el procedimiento de `docs/SPEC.md` §12, incluida la notificación a la Superintendencia de Protección de Datos Personales dentro del plazo legal.
